# Online-C-Compiler
A free online C compiler that builds Windows EXE files using GitHub Actions. No compiler installation required.


Free Online C Compiler 🚀

A free online C compiler powered by GitHub Actions.

Compile your C source code into a Windows executable (.exe) without installing any compiler or development environment on your computer.

How It Works

Simply add this repository to your GitHub account, replace the main.c file with your own C code, run the GitHub Actions workflow, and download the compiled executable.

No Visual Studio installation.
No local compiler setup.
Just push your code and build.

Features
✅ Free C compiler online
✅ Automatically builds Windows .exe files
✅ Powered by GitHub Actions
✅ No software installation required
✅ Simple and beginner-friendly
Usage
Fork this repository.
Replace main.c with your own C source code.
Go to the Actions tab.
Run the Build EXE workflow.
Download your compiled .exe file from Artifacts.
